# Contributing

Thanks for improving DSH QQ Console.

1. Fork the repository and create a feature branch.
2. Keep changes focused; update `.selftest/v2.mjs` when behavior changes.
3. Run `npm run check` and `npm test` before opening a pull request.
4. Do not commit credentials, user data, logs, or local deployment paths.
5. Describe the user-visible behavior and the verification you ran in the PR.

For security issues, follow [SECURITY.md](SECURITY.md).
